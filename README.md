# darkAI

A simple ChatGPT-style AI chat app with a dark interface.

## Run locally

1. Install Node.js 18 or newer.
2. Copy `.env.example` to `.env`.
3. Add your OpenAI API key to `.env`.
4. Run:

```bash
npm install
npm start
```

5. Open http://localhost:3000

Never commit your real API key. The `.env` file is ignored by Git.
